# QuakeScope

A real-data earthquake explorer by Abril Mesa. Explore a week of seismic activity through an interactive map, location search, magnitude and depth filters, charts, and a downloadable catalog.

## What this app does

- Plots earthquakes at their actual latitude and longitude.
- Shows event count, largest magnitude, average depth, and the count of magnitude 4.5+ events.
- Filters by location text, time window, magnitude, and depth.
- Shows daily activity and magnitude distribution for the same filtered records.
- Lets visitors inspect individual earthquake details, sort the catalog, and download filtered results as CSV.
- Loads a saved real dataset by default and optionally refreshes from the public USGS feed.
- Adapts to phones and larger screens.

## Data source and provenance

Source: [USGS GeoJSON Summary Feed](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php).

Feed URL: https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_week.geojson

The included snapshot was generated by USGS on **October 27, 2026 at 22:57:03 UTC**. It contains 1,914 seismic records. The app displays **1,871 earthquake events** with a numeric magnitude, timestamp, valid coordinates, and numeric depth. Other types of seismic events are excluded. The original GeoJSON is preserved in `data/earthquakes.geojson`. `data/earthquakes.csv` is an export of the 1,871 included events for inspection or use in Tableau.

The data is real, not randomly generated or a sample fabricated for the interface. Records can be revised by USGS. Different magnitude types are present, and network coverage varies by region. Global counts should not be interpreted as complete counts of all earthquakes everywhere. Negative magnitudes and negative depths are retained when supplied by the source.

Time-window filters are relative to the dataset generation time displayed in the app. The saved snapshot stays usable after its original week has passed. A successful refresh updates the dataset in the visitor's browser for that session; it does not overwrite the copy in GitHub. If the live feed is blocked or unavailable, the currently loaded dataset remains usable.

Map boundaries: [johan/world.geo.json](https://github.com/johan/world.geo.json), stored locally in `data/world.geojson`. The map is a simple equirectangular world overview, not a navigation or emergency-response tool. Map circles indicate location and relative magnitude; they are not impact zones. Colors distinguish magnitudes below 2.5, from 2.5 to below 4.5, and at least 4.5.

## Technology

HTML, CSS, JavaScript, SVG, and GeoJSON. No database, API key, paid AI subscription, or build step is needed. Fonts are optional downloads from Google Fonts, with system font fallbacks. Data, map shapes, charts, and application code are bundled locally.

## Deploy on Vercel

1. Upload this folder's **contents** to the root of your GitHub repository. `index.html`, `app.js`, `model.js`, `styles.css`, `favicon.svg`, `vercel.json`, and the `data` folder should appear at the repository root.
2. In Vercel, choose **Add New → Project**, find the repository, and choose **Import**.
3. Use **Framework Preset: Other**, the repository root as **Root Directory**, no build command, and **Output Directory: `.`**. No environment variables are required. The included `vercel.json` supplies the build/output settings.
4. Choose **Deploy**, wait for completion, and open the URL Vercel gives you.

If the Vercel project is already linked to this same repository and production branch, a new commit normally triggers deployment automatically. Confirm the deployment status and open the website before submitting it.

Official instructions: [Vercel build configuration](https://vercel.com/docs/builds/configure-a-build) and [Git deployment](https://vercel.com/docs/git).

## Preview locally

Serve this directory with a static web server. For example, if Python is installed:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Double-clicking `index.html` may block local data loading; use the hosted site or a local server instead.
